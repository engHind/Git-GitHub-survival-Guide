# Git & GitHub Survival Guide
A beginner-friendly guide to the essential Git commands and GitHub workflows.
# About the Project
This project summarizes the key concepts learned during the Git and GitHub training program. It provides simple explanations of common commands and practical workflows.
# Git Basics
Command   | Purpose
git init  | Initialize a Git repository
git status| Check the current working tree status
git add   | Stage changes for a commit
git commit| Save staged changes in the repository history
git log   | View commit history
# Branches and Collaboration
Command     | Purpose
git branch  | List branches
git switch  | -c branch-name Create and switch to a new branch
git push    | Upload local commits to a remote repository
Pull Request| Propose changes and review them before merging
Merge       | Integrate changes from one branch into another
# Typical Workflow
1. Create a branch for your changes.
2. Edit or add files.
3. Stage and commit your changes.
4. Push the branch to GitHub.
5. Open a Pull Request.
6. Review and merge the changes into main.
# Learning Goals
- Understand version control fundamentals.
- Practice branching and meaningful commits.
- Learn how Pull Requests support collaboration.
- Build confidence using GitHub.
